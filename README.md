# Library Management System

Десктопное приложение для управления библиотекой, разработанное на Java (Swing) с использованием базы данных PostgreSQL. Проект делает особый акцент на безопасность, аутентификацию и управление жизненным циклом учетных записей пользователей.

## Обзор архитектуры
Приложение построено с четким разделением слоев (UI, Модели, База данных, Утилиты), что делает код легко поддерживаемым и масштабируемым.

### Ключевые модули
*   **Слой UI (`library_app.ui`):** Графические интерфейсы, написанные на Java Swing. Включают `LoginForm` с интерактивной графической капчей, `AdminDashboardForm` для управления пользователями и `ChangePasswordForm` для форсированной смены пароля при первом входе.
*   **Доступ к данным (`DatabaseHelper.java`):** Инкапсулированный Data Access Object (DAO) для работы с PostgreSQL. Все запросы используют `PreparedStatement`, что полностью исключает риск SQL-инъекций.
*   **Безопасность (`CryptoUtils.java`):** Утилитарный класс для хэширования паролей. В базе данных пароли хранятся исключительно в виде хэшей (реализовано с использованием алгоритма MD5).

## Реализованные механизмы безопасности
В проекте реализованы стандарты безопасности корпоративного уровня (Enterprise Security Patterns):
1.  **Защита от брутфорса:** Учетная запись блокируется после 3 неудачных попыток входа (`failed_attempts`).
2.  **Защита от неактивности:** Автоматическая блокировка аккаунта, если с момента последнего входа (`last_login`) прошло более 30 дней.
3.  **Принудительная смена пароля:** При первом входе в систему (флаг `is_first_login`) пользователь обязан сменить сгенерированный администратором пароль.
4.  **Кастомная капча:** Интерактивная графическая капча на форме логина в виде пазла (пользователь должен собрать картинку в правильном порядке).
5.  **Хэширование паролей:** Пароли передаются и хранятся в виде криптографических хэшей.

## Стек технологий
*   **Язык:** Java
*   **GUI:** Java Swing
*   **База данных:** PostgreSQL
*   **Криптография:** `java.security.MessageDigest`
*   **Сборщик:** Maven

## Развертывание

### Подготовка базы данных
Необходимо создать базу данных `library_db` и таблицу `users` со следующими полями:
`id` (SERIAL PRIMARY KEY), `username` (VARCHAR), `password_hash` (VARCHAR), `role` (VARCHAR), `is_first_login` (BOOLEAN), `failed_attempts` (INT), `last_login` (TIMESTAMP), `status` (VARCHAR).

Учетные данные для подключения по умолчанию (`postgres` / `1234`) можно изменить в классе `DatabaseHelper.java`.

### Запуск
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="library_app.Main"
```
